# Дамеля, пойдём погулять

Личное письмо-приглашение от Тлеу. Дамеля открывает конверт, пишет куда хочет (или берёт афишу) и кладёт записку в карман — открывается WhatsApp. Сайт статический, без сервера.

## Как выложить на GitHub Pages

1. Создайте репозиторий. Имя лучше латиницей, например `damelya-invite` — так ссылка будет короткой.
2. Залейте проект (папка `docs/` должна быть в корне репо).
3. **Settings → Pages**.
4. **Source:** Deploy from a branch.
5. Branch: `main`, folder: **`/docs`**.
6. Сохраните. Через минуту сайт: `https://<username>.github.io/<repo>/`.

В `docs/` есть `.nojekyll`. Ссылку Дамеле лучше отправить лично: номер WhatsApp лежит в `docs/data/invite.json` и будет доступен по адресу сайта.

Репозиторий можно сделать **private** — сам сайт всё равно публичный, зато код не ищут на GitHub.

## Как открыть локально

```bash
node serve.js
```

Откройте http://127.0.0.1:8765/ , ширина около 360px. Не открывайте `docs/index.html` как файл.

## Что уже подставлено

В [`docs/data/invite.json`](docs/data/invite.json): Дамеля, номер Тлеу, места и три афиши. Код трогать не нужно.

Фото-заглушки (SVG) можно заменить своими кадрами, поправив пути в JSON: `docs/images/places/`, `docs/images/posters/`.
